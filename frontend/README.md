Comsierge Frontend
==================

This is the frontend for the Comsierge platform, a unified SMS and AI messaging dashboard.

## Structure

- Built with Next.js (App Router)
- Modular component-based architecture
- Dashboard UI with sidebar navigation, stats, and high-priority messages

### Folder Structure

```
/app
  /dashboard
    /components
      Sidebar.js
      Header.js
      StatsCards.js
      HighPriorityMessages.js
      MessageCard.js
  /login
  /settings
```

## Getting Started

Install dependencies and run the development server:

```
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
